# Island 1.3.0 for Windows

Native Windows dynamic island with media controls, hover transport, volume/brightness HUDs, actual WASAPI spectrum visualization, calendar/activity widgets, and 17 tool pages inside the island. Includes 50 custom vector icons, event-driven play/pause updates and response/damping spring presets.

Extract Island-Windows-x64.zip and run Island.exe with the included runtime files. Quit an older Island instance first. Windows 10 build 19041 or later, x64. No separate .NET installation is required.

Development build: unsigned portable executable; Windows may show an unfamiliar-publisher prompt. This release does not implement every feature of the macOS apps that inspired it. See Feature-Coverage-1.3.md for integration limits. Hardware-dependent camera, brightness, notification and media behavior varies by device/app. Constant 60 FPS is not guaranteed.

Validation: 156 built-in self-checks and 9 local HTTP API checks. No signing certificate, API token, user notes or local settings are distributed.
